Privacy Policy

Effective: November 2026. Applies to the Framework Crate Windows desktop app.

Short version: Framework Crate works fully offline. It collects no personal data, creates no accounts, runs no analytics or tracking, and sends nothing anywhere unless you explicitly press a button that needs the network.

Data stored on your device

Everything the app needs lives on your own PC, under %APPDATA%\framework-crate:

  • Settings (config.toml) — your fan curves, charge limit, telemetry and theme choices.
  • BIOS power defaults (bios_defaults.toml) — a snapshot of factory CPU power limits used by Reset.
  • Log file (app.log, size-rotated) — local warnings/errors for diagnosing issues.

Hardware readings (temperatures, fan RPM, battery and PD state) are processed in memory to drive the UI and fan control. They are never uploaded.

Network use (only on your explicit action)

  • Check for updates (About page button) — queries the GitHub API (api.github.com) for this repository's latest release tag. Notification only; nothing is downloaded.
  • PawnIO install / module download (CPU Power page buttons) — downloads signed components from the official PawnIO sources (winget, github.com/namazso/PawnIO.Modules) over HTTPS. Optional; the rest of the app works without it.

The app performs no background network polling and contacts no other servers.

Permissions

The app requests administrator privileges because the embedded-controller driver and CPU power registers require them. Elevated rights are used solely for local hardware access.

Children

The app collects no data from anyone, including children under 13.
