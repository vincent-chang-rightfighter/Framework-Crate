Framework Crate is an independent open-source project. Contributions that help most:

  • Report bugs — attach logs from %APPDATA%\framework-crate\app.log, your model, and BIOS version.
  • Verify on hardware the maintainer doesn't have — multi-fan machines (Framework 16 / Desktop), new BIOS versions — and try pre-releases early.
  • Improve docs and code — fix wording, add translations, or send small tested pull requests (Rust + Iced; layout under src/app, src/views, src/cpu_power, src/config).
  • Security reports — use the private process on the Security page.

AI-assisted changes

AI coding agents are allowed. Every pull request or patch must state:

  • Why — the problem being solved and the reasoning behind the change.
  • Scope — how many files changed and which areas they touch.
  • Verification — the tests run and their results, plus any behavior impact.
