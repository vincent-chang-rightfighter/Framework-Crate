Framework Crate

A native Windows desktop GUI for Framework laptop fan control, battery charge limits, and live hardware telemetry. Built with Rust and Iced, using framework_lib for direct EC hardware access.

Download Source code

Prebuilt framework-crate.exe binaries are attached to each GitHub Release. Run as administrator.

Features

  • Fan Control — Auto (firmware), manual duty 0–100% (optional per-fan; at or above 95 °C duty is floored at 90%), and curve mode with draggable points on a canvas (default 5 points, hysteresis and rate limiting, live sensor markers; optional per-fan curves on multi-fan machines via the Unified switch; calibration wizard measures per-fan RPM tables for accurate ramp seeding).
  • Battery Management — Maximum charge limit 25–100% with enable/disable toggle; the saved limit is applied on startup. Health from last-full / design capacity. Details shows charger voltage/input on AC plus smart-battery data (per-cell voltages, pack temperature, safety alerts) when readable.
  • Live telemetry — Real-time temperature chart (15/30/60 s window), per-sensor display with colored indicators, fan RPM in the header.
  • CPU Power (Intel only, optional PawnIO) — PL1/PL2 read/write with live turbo readout. Original factory limits are saved on the first AC run for Reset. Writes go to MSR 0x610 only (MMIO mirror is read-only); per-model caps apply (Laptop 12 → 40 W, 13 → 70 W, 16 → 100 W, Desktop → 120 W).
  • Misc — Camera/mic privacy switch states, keyboard backlight slider, fingerprint LED level, USB-C / HDMI / DP port classification inferred from PD state.
  • System tray & startup — Minimize to tray with temperature tooltip (auto-restored if Explorer restarts); per-user logon task with battery conditions cleared and restart on failure.
  • About page — Hardware info, PD controller firmware, poll settings, manual-download helpers, and third-party license notices.

Requirements

  • Framework Laptop, Intel Core Ultra Series 1 (Meteor Lake) — the only tested platform
  • Windows 10/11, administrator privileges (EC access, CPU power writes, startup task)
  • PawnIO is optional and only needed for the CPU Power card; everything else works with the Framework EC driver alone

Settings live in %APPDATA%\framework-crate\config.toml; factory power defaults in bios_defaults.toml; warnings/errors in app.log (rotated).
