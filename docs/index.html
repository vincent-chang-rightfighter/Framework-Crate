Framework Crate

A native Windows desktop GUI for Framework laptop fan control, battery charge limits, and live hardware telemetry. Built with Rust and Iced, using framework_lib for direct EC hardware access.

Download Source code

Prebuilt framework-crate.exe binaries are attached to each GitHub Release. Run as administrator.

Features

  • Fan Control — Auto (firmware), manual duty, and curve mode with draggable points; optional per-fan curves and a calibration wizard that measures per-fan RPM tables.
  • Battery — Charge limit with toggle, health estimate, and Details (charger input, smart-battery data).
  • Live telemetry — Temperature chart, per-sensor display, fan RPM in the header.
  • CPU Power (Intel only, optional PawnIO) — PL1/PL2 read/write, turbo readout, BIOS-default reset.
  • Misc — Camera/mic privacy switch states, keyboard backlight, fingerprint LED, PD-inferred port labels.
  • System tray — Minimize to tray, temperature tooltip, launch at startup.

Requirements

  • Framework Laptop, Intel Core Ultra Series 1 (Meteor Lake)
  • Windows 10/11, administrator privileges (EC access)
