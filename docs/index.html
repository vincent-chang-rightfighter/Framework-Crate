Key features

  • Curve editor — draggable points, hysteresis, per-fan curves, RPM calibration.
  • CPU power — PL1/PL2 read/write, turbo readout, factory reset, separate AC/Battery profiles with optional keep-alive after sleep and AC changes.
  • Battery care — charge limit, health, smart-battery details.
  • Telemetry — temperature chart, sensor readouts, privacy switches, port labels.

Tested on Framework Laptop with Intel Core Ultra Series 1; Windows 10/11 and administrator rights required. No accounts, no telemetry.
