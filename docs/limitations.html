What the app cannot do today, so you can judge fit before installing.

  • AMD CPU Power is Intel-only. On AMD and other CPUs the CPU Power card shows Not Supported and no power-limit access is attempted.
  • MMIO mirror is read-only. The official Intel MCHBAR module exposes reads only, so Apply/Sync writes MSR 0x610 alone. If firmware holds the MMIO mirror below your MSR value, the enforced limit may not move.
  • Tested platform is narrow. Only Intel Core Ultra Series 1 (Meteor Lake) Framework laptops are tested; the Framework EC kernel driver must be installed.
  • Per-fan curves lack multi-fan verification. Covered by mocked unit tests only — no Framework 16 / Desktop hardware was available. Single-fan machines use the exact pre-existing code path.
  • Crash keeps the last state. Orderly quit restores firmware fan control and flushes the charge limit, but a crash or kill bypasses that path: the EC keeps the last written fan duty until sleep, reboot, or the next launch.
  • Logoff handover is unreliable. On some Windows 11 elevated setups the session-end broadcast never reaches the tray window, so manual/curve duty can persist after sign-out. Use Restore Auto & Exit before logging off when the fan is under manual/curve control.
  • HDMI/DP cards without DP-alt may be mislabeled. Port type is inferred from PD state; cards that omit DP-alt mode while drawing ~3–5 W can show the wrong label. Ports Debug Mode on the About page shows the raw role/watts.
